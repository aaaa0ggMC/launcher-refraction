# 折光航标 · Refraction

一个没有倒计时的光路解谜游戏。玩家不是操纵角色跑跳，而是观察一张始终可见的光学网络，旋转镜片，让所有航标同时亮起。

## 设计

- **即时反馈**：每次旋转立即重算整条光路，错误也能解释下一步选择。
- **先学规则，再组合规则**：六个手工关卡依次引入转弯、连续反射、障碍、分光、多目标、交叉网络。
- **低压力、可推敲**：没有生命值和倒计时，支持撤销、重置、自由选关。参考步数是已穷举验证的最优旋转次数。
- **界面与命令同权**：游戏状态在主进程中，所有动作通过命令注册表；乐观版本号防止旧视图覆盖新操作，独占 SDK 保证用户优先。

光源发射光束；镜面 `/` 与 `\` 将光转向；分光器保留直行光束并产生反射光束；航标、岩石和光源吸收入射光。光线出界后终止。所有航标必须同时点亮才算通关。

## 实现边界

不联网、不读取个人资料、不写存档，不增加 npm 依赖。棋盘和最好成绩保留到应用退出；切换页面不丢失。最多保留 512 次可撤销操作，达到后应撤销或重置。

`engine.ts` 为纯函数，按「格子 + 出射方向」去重，分光环路的计算量有界。`game.ts` 处理版本、撤销和本次运行成绩；`commands.ts` 接入独占和 CLI。

## 命令

先调用 `refraction.state` 取得当前 `revision`，每个写操作传入这个值；操作后使用返回的新版本号。坐标从 0 开始。

```text
refraction.state
refraction.rotate --x 3 --y 3 --revision 0
refraction.undo --revision 1
refraction.load --level 4 --revision 2
refraction.reset --revision 3
```
