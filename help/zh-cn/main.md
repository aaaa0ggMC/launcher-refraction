# 折光航标

> 最后更新：2026-10-02

折光航标是一个安静的光路解谜游戏：棋盘上有一个固定方向发光的光源、若干可以旋转的反光镜与分光镜、若干需要点亮的灯塔，以及会吸收光束的岩石。你的任务只有一个——**同时点亮所有灯塔**。没有计时、没有失败、没有操作频率要求，想多久都可以。

> 一句话上手：打开折光航标页面 → 点棋盘上的反光镜旋转它 → 让光束抵达每一座灯塔 → 全部亮起即通关，可以继续下一关，也可以撤销、重置后再来。

## 规则

- 棋盘是正方形，格子坐标从 1 开始（第 1 行第 1 列在左上角）。
- 光源方向固定，持续射出一束光，光束沿直线前进。
- **反光镜**：点击后在 `/` 与 `\` 两种朝向之间切换，把光束拐一个 90° 的弯。
- **分光镜**：既是一面镜子，也是一条通道——射入的光束**直穿过去**，同时**按自身朝向额外反射出一束**，因此一束光进去会有两束光出来。
- **灯塔**：被任意一束光照到即点亮；熄灭只是因为光没送到，不计时也不会自动熄灭。
- **岩石**：吸收射入的光束，光路到此为止。
- 通关条件：**所有灯塔同时点亮**，不看步数；一束光可以先后经过多面镜子。
- 每一步「步数」只统计**旋转次数**：旋转一次反光镜或分光镜 = 1 步，撤销会退回一步，重置整个关卡回到初始布阵。

棋盘上的每一格都是可聚焦按钮：Tab 聚焦、Enter 或空格旋转。灯塔与岩石等不可旋转的格子会被禁用，但仍带有可读的无障碍名称（第几行第几列 · 是什么）。

## 常见操作

### 旋转与撤销

- 点击（或聚焦后按 Enter / 空格）任意反光镜或分光镜即可旋转，每转一次记 1 步。
- **撤销** 退回上一次旋转；通关后依然可以撤销——撤销之后棋盘回到未点亮状态，可以换个思路再试。
- **重置本关** 放弃当前全部操作，回到该关的初始布阵，步数归零。
- 所有操作期间按钮会暂时禁用，避免连点造成结果错乱。

### 刷新与命令行同步

页面每 1.5 秒会自动向引擎读取一次状态，因此**在命令行里一样能玩**：CLI 的每一步都会自动反映到界面上，反之亦然。

### 存档与进度

- **没有长期存档**：最佳步数只保存在内存中，退出程序即清空，不写任何配置文件。
- 切换页面再回来棋盘与最佳纪录都还在（引擎持有状态），退出程序后才清空。
- 六个关卡全部开放，不存在锁定或解锁条件。

### 独占控制

同一时刻只有一位掌控者（你，或通过 MCP / Remote 接入的 AI）能操作游戏棋盘；页面顶部的提示会点出这个范围（界面里叫「游戏棋盘」）。AI 占用时由外壳统一处理接管，不需要在本页面做任何设置。

## 命令行

所有操作都是注册命令，界面按钮与命令行共享同一套逻辑。

读取当前状态（每次变更前的第一步）：

```
refraction.state
```

返回值包含 `level`（含 `pieces` 布阵与 `par` 标杆）、`moves`、`beams`（光束线段）、`lit`（已点亮的灯塔）、`won`、`canUndo`、`best`、`revision` 与 `levelCount`。

写入类命令都要带上**最近一次读到的 `revision`**，引擎用它拒绝过期写入（避免两个人的操作互相覆盖）：

```
refraction.rotate --x 3 --y 4 --revision 42
refraction.undo --revision 42
refraction.reset --revision 42
```

`--x` / `--y` 是从 0 开始的格子坐标；旋转只对反光镜与分光镜有效。切换关卡（1 开始的关卡号）：

```
refraction.load --level 2 --revision 42
```

任一步失败时页面会显示可读的错误信息并立即刷新状态，不会留下半套旧棋盘。

## 深入阅读

- 分光镜的关键在「直穿 + 反射」：把分光镜想成一扇半开的门，直行走原来那束，旁边再多出一束。
- 岩石既是障碍也是路标：它迫使光路绕开，往往正好指向灯塔所在的方向。
